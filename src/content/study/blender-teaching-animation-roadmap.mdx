## 01 / 我的学习目标

我的目标不是成为专业 Blender 建模师，而是：

> 使用 Blender + GPT / Codex 制作结构清楚、画面舒适、可复用的 3D 教学动画。

因此学习重点不是复杂建模，而是：

- Blender 基础操作
- 简单模型创建
- 坐标系与父子关系
- 材质
- 灯光
- 相机
- 动画
- 物体约束
- 渲染
- 后续结合 GPT / Blender Python / MCP 自动化

目前不需要系统学习人物建模、雕刻、高级拓扑、复杂 UV、毛发、角色绑定、复杂粒子系统和写实级 PBR 资产制作。

<strong>阅读方式：</strong>先完成精选章节和第一个教学 Demo，再根据项目遇到的问题补学 Blender。

## 02 / Kurt 这套教程值得看吗？

结论：

> **值得看，但不建议从头到尾完整刷完。**

这是一套比较成熟的 Blender 中文零基础课程，非常适合建立 Blender 的基础认知。

但课程面向的是普通 Blender 学习者，其中包含不少角色建模、UV、粒子、骨骼、高级材质和特效内容，这些并不是当前“3D 教学动画”最需要的内容。

因此推荐采用：

> **选择性学习 + 项目驱动**

而不是从第一集一路完整刷到最后。

## 04 / 第一阶段：基础操作

必须熟练以下内容：

- Object Mode
- Edit Mode
- Location
- Rotation
- Scale
- 世界坐标系
- 局部坐标系
- G：移动
- R：旋转
- S：缩放
- X / Y / Z：限制方向
- Duplicate
- Delete
- Undo
- Collection

这一阶段的目标不是操作得特别快，而是：

> 能明确知道一个物体为什么位于当前位置，以及如何准确移动、旋转和缩放。

## 05 / 第二阶段：只学习够用的简单建模

教学动画通常不需要复杂模型。

优先掌握：

- Cube
- Plane
- Cylinder
- Sphere
- Cone
- Curve
- Text
- Extrude
- Inset
- Bevel
- Modifier 基本概念

这些已经足够制作 IMU、无人机简模、小车、传感器、箭头、坐标轴、运动轨迹、相机模型、GNSS 卫星和教学示意结构。

现阶段不要追求复杂模型。

目标应该是：

> **模型足够表达教学内容即可。**

## 06 / 2.6 曲线与父子级非常重要

对于教学动画，这一节的重要程度甚至高于很多复杂建模内容。

例如：

```text
Drone
└── IMU
    ├── X Axis
    ├── Y Axis
    └── Z Axis
```

如果 IMU 和 XYZ 坐标轴都属于无人机：

```text
无人机旋转
    ↓
IMU 自动跟随
    ↓
XYZ 坐标轴自动跟随
```

这样就不需要分别给每个对象制作动画。

### Parent 父子关系重点理解

需要理解：

- Parent 是什么
- Child 是什么
- 父对象移动时子对象会发生什么
- 父对象旋转时子对象会发生什么
- Local Coordinate 与 World Coordinate 的区别

这些知识以后做 IMU、无人机、机器人、相机、坐标系和多传感器系统都会大量使用。

## 07 / Curve 对教学动画非常有价值

Curve 可以用于：

- 运动轨迹
- 箭头
- 向量
- 路径
- 数据曲线
- Camera 运动路径
- 无人机轨迹
- IMU 运动路线
- GNSS 信号路径
- VIO 运动轨迹

因此 Curve 不应该当作普通建模知识跳过去。它以后会成为教学动画中的高频工具。

## 08 / 第三阶段：材质只学够用的

目前不需要深入研究复杂材质。

优先理解：

- Material 是什么
- Principled BSDF 是什么
- Base Color
- Roughness
- Metallic
- Alpha
- Emission

目标是能够创建主体材质、辅助材质、高亮材质、半透明材质和发光强调材质。

对于教学动画来说，材质首先服务于：

> **信息分类。**

而不是追求照片级真实。

## 09 / 建立固定的教学配色

推荐以后逐渐形成固定视觉风格。

### 背景

- 浅灰
- 米白
- 很淡的暖灰

### 主体

- 蓝色
- 深灰
- 低饱和颜色

### 重点信息

- 橙色
- 黄色

### 辅助信息

- 浅灰
- 低饱和蓝灰

例如：

```text
主体：蓝色
重点：橙色
次要结构：灰色
背景：浅灰
文字：深灰
```

这样可以减少每个项目重新设计视觉风格的时间。

## 10 / 第四阶段：灯光比复杂建模更重要

我的目标是：

> 模型不用特别精致，但是整体画面需要舒服。

因此优先级应该是：

```text
灯光 + 相机 + 构图 + 材质 > 复杂建模
```

一个非常普通的 Cube，如果配合大面积 Area Light、柔和辅助光、简单统一的材质、干净背景和合适的 Camera，也能做出非常舒服的教学画面。

因此 Kurt 的以下章节需要重点学习：

- 5.1 布光
- 5.2 场景搭建 / 第三方素材
- 5.3 场景布光练习

## 11 / 建立自己的基础灯光模板

以后可以建立一个固定的 `Teaching_Template.blend`，里面提前准备：

```text
Camera

Key Light
Fill Light

Background

Basic Material
Highlight Material
Transparent Material

XYZ Axis
Arrow

```

以后每次制作新教学动画时直接复制模板，而不是从空场景重新开始。

## 12 / 第五阶段：动画是整个路线的核心

重点掌握：

- Timeline
- Frame
- Keyframe
- Location 动画
- Rotation 动画
- Scale 动画
- Camera 动画
- Interpolation
- Graph Editor
- Constraint

例如：

```text
Frame 1
Z Rotation = 0°

Frame 90
Z Rotation = 90°
```

Blender 会自动完成中间过程。

必须真正理解：

> 动画本质上不是一帧一帧手动移动物体，而是在关键状态之间插值。

## 13 / 一定要理解动画插值

初学者动画非常容易出现：

```text
突然启动
    ↓
匀速运动
    ↓
突然停止
```

这种动画虽然“能动”，但是看起来很像 PPT。

舒服的动画通常是：

```text
缓慢启动
    ↓
平稳运动
    ↓
缓慢停止
```

因此至少需要理解：

- Linear
- Bezier
- Ease In
- Ease Out
- Ease In / Out

后续再逐渐学习 Graph Editor。

## 14 / 不要急着深入 Graph Editor

第一阶段只需要知道：

> Graph Editor 用来控制动画属性随时间变化的曲线。

例如：

```text
Rotation
   ↑
   │            ______
   │          /
   │        /
   │      /
   │_____/
   └────────────→ Time
```

之后真正遇到动画太突然、运动速度不舒服、Camera 移动僵硬或旋转速度不自然时，再回来深入学习即可。

## 15 / 6.5 物体约束非常值得学

例如，希望 Camera 永远看向 IMU。

没有必要手动不断调整 Camera Rotation。

可以使用：

```text
Camera
  ↓
Track To
  ↓
IMU
```

这样：

```text
IMU 移动
    ↓
Camera 自动调整方向
    ↓
始终看向 IMU
```

以后教学动画中会大量遇到类似需求。

建议重点了解：

- Track To
- Copy Location
- Copy Rotation
- Follow Path

不需要一次性学完所有 Constraint。

## 16 / 第一阶段明确不要学的东西

目前暂时跳过：

- 人物雕刻
- 高级拓扑
- 复杂 UV
- 毛发
- 复杂粒子
- 高级角色 Rigging
- 写实人物
- 复杂皮肤材质
- 影视级特效

原因不是这些知识没有价值，而是它们与当前制作教学动画的目标关系较弱，学习成本非常高。

真正需要时再学习。

## 19 / 第一个项目：IMU 三轴旋转教学 Demo

不建议继续跟教程制作复杂角色。

第一个真实项目直接制作：

> **IMU 三轴旋转教学动画**

### 场景组成

```text
Cube
  ↓
IMU

Cylinder + Cone
  ↓
X / Y / Z 三轴箭头

Text
  ↓
X / Y / Z

Plane
  ↓
地面

Camera

2 × Area Light
```

模型不需要复杂。

## 20 / 第一个项目动画设计

### Frame 1

IMU 静止，展示基本模型。

### Frame 40

XYZ 坐标轴出现，让观众理解 IMU 自身坐标系。

### Frame 80

IMU 绕 Z 轴旋转 45°，突出 Z Axis + Rotation。

### Frame 120

IMU 绕 X 轴旋转 30°，继续展示三维旋转关系。

### Frame 160

Camera 缓慢移动，从另一个角度观察整个坐标系。

最终输出：

> **20～30 秒左右的教学 Demo。**

## 21 / 第一个项目的验收标准

### 1. 结构是否清楚

观众能不能快速看懂：

- 哪个是 X
- 哪个是 Y
- 哪个是 Z
- IMU 在怎样旋转
- 哪个坐标系属于 IMU

### 2. 画面是否舒服

检查：

- 背景是否干净
- 灯光是否柔和
- 颜色是否统一
- 标签是否清楚
- 主体是否突出
- 是否存在无意义的视觉元素

### 3. 动画是否自然

避免突然启动、突然停止。

应该逐渐学习控制：

- Ease In
- Ease Out
- 动画持续时间
- 动作节奏

### 4. 镜头是否稳定

不要为了“炫酷”频繁旋转 Camera。

教学视频首先应该：

> **清楚**

其次才是：

> **好看**

最后才是：

> **炫酷**

## 23 / 开始学习 Blender Python

不需要系统学习整个 Blender Python API，只需要理解基本思路。

例如：

```python
import bpy

bpy.ops.mesh.primitive_cube_add(
    location=(0, 0, 1)
)

obj = bpy.context.object

obj.scale = (2, 1, 0.5)

obj.rotation_euler[2] = 0.5
```

只需要能够理解：

```text
创建 Cube
    ↓
获取当前对象
    ↓
改变尺寸
    ↓
改变旋转
```

具体代码以后可以大量交给 GPT / Codex 编写。

## 24 / GPT 的正确使用方式

初期不要直接说：

> 帮我生成完整教学动画。

而应该分步骤：

```text
教学需求设计
    ↓
让 GPT 完成一个小任务
    ↓
在 Blender 中运行
    ↓
检查结果
    ↓
修改
    ↓
完成下一个小任务
```

例如：

1. 创建一个蓝色 IMU 方块。
2. 添加 XYZ 坐标轴。
3. 给三个坐标轴添加箭头。
4. 添加 X / Y / Z 标签。
5. 制作绕 Z 轴旋转的动画。
6. 设置 Camera 和灯光。
7. 最后把整个过程整理成一个完整 Blender Python 脚本。

## 25 / 什么时候接入 MCP / Agent？

不要一开始就依赖 MCP。

推荐顺序：

```text

    ↓

    ↓

    ↓

    ↓
```

这样即使 AI 操作失败，也知道大概是什么地方出了问题，而不是完全依赖 AI。

## 29 / 核心原则

整个学习过程中始终坚持：

> **不是为了学 Blender 而学 Blender。**

而是：

> **为了把知识讲清楚而使用 Blender。**

最终目标也不是成为专业 3D 建模师，而是形成：

> **使用 AI + Blender 快速制作清楚、舒服、可复用的 3D 教学动画的能力。**
