**本篇目标：**大模型是带概率性的外部依赖。工程上要定义输入输出契约、处理失败、记录成本并持续评估。

## 01 / 模型与 API

### LLM-01｜模型工作原理的工程视角 · P0 / L1

理解 Token、上下文窗口、概率生成和 Attention 的基本直觉。**验收：**解释幻觉、遗漏和长上下文失效可能如何出现，以及为什么模型输出不是事实保证。

### LLM-02｜模型 API 调用 · P0 / L2

理解认证、请求、响应、错误分类和模型切换。**验收：**写统一客户端，覆盖超时、有限重试和可区分的错误类型。

### LLM-03｜Prompt 设计 · P0 / L2

掌握角色、任务、输入边界、示例和约束。**验收：**为文章信息抽取设计 Prompt，并与无约束版本在固定样例上比较。

### LLM-04｜结构化输出 · P0 / L2

理解 JSON Schema、Pydantic 校验和失败重试。**验收：**结果严格符合指定结构；格式错误有可靠处理，不直接信任模型文本。

## 02 / 成本、质量与安全

### LLM-05｜Token 与成本 · P1 / L2

理解输入/输出 Token、价格、批处理和缓存。**验收：**估算分析 1,000 篇文章成本，并记录实际用量和误差来源。

### LLM-06｜速率限制与可靠性 · P1 / L2

理解 429、5xx、指数退避、限流和幂等。**验收：**临时失败后可以恢复，且不会重复触发邮件等外部副作用。

### LLM-07｜Prompt 评估 · P1 / L2

建立固定测试集，关注准确率、格式通过率和回归。**验收：**用至少 20 条样例比较两版 Prompt，列出失败原因。

### LLM-08｜模型选择 · P1 / L2

比较推理能力、速度、成本、上下文、隐私与部署限制。**验收：**同一任务比较两种可用模型并写出有证据的选择理由。

### LLM-09｜安全意识 · P0 / L2

理解不可信输入、提示注入、敏感信息和数据外发风险。**验收：**恶意网页要求泄密或越权时，系统仍执行服务端权限边界。

### LLM-10｜Embedding 基础 · P0 / L2

理解文本向量、维度、语义相似和余弦相似度。**验收：**用代码计算相似度，并解释“向量相近”不代表事实正确。

## 03 / 通关作品

### 文章结构化抽取服务

输入文章，返回严格校验的标题、公司、事件、日期和证据句 JSON。附至少 20 条样例的通过率、失败分类和 Token 统计；密钥通过环境配置，不进入仓库。
