**本篇目标：**不只是会写脚本，而是能组织模块、管理依赖、处理外部输入、记录故障并交付可复现程序。阶段完成时留下代码、测试或运行记录。

## 01 / 语言与项目基础

### PY-01｜基本语法、集合与推导式 · P0 / L2

理解 `list/dict/set/tuple`、迭代、切片、推导式以及可变/不可变对象。**验收：**读取一批 JSON，完成去重、筛选和聚合，并独立写成函数。

### PY-02｜函数、模块与包 · P0 / L2

掌握参数、返回值、作用域、`import` 和包组织。**验收：**把单文件采集程序拆成采集、解析、清洗、存储模块，不产生循环依赖。

### PY-03｜虚拟环境与依赖 · P0 / L2

理解 `venv`、`pip`、版本锁定和环境隔离。**验收：**新环境按 README 命令即可安装依赖并运行，不依赖个人机器状态。

## 02 / 输入输出与服务调用

### PY-04｜文件与序列化 · P0 / L2

掌握 UTF-8、路径、JSON/CSV、上下文管理器。**验收：**正确处理中文路径、字段缺失和异常编码，读写结果可往返验证。

### PY-05｜HTTP 客户端 · P0 / L2

使用 `requests` 或 `httpx`，理解状态码、分页、超时和有限重试。**验收：**调用公开 API，覆盖分页与临时失败，不会无限循环或重复产生副作用。

### PY-06｜异常、日志与配置 · P0 / L2

掌握异常边界、`logging`、环境变量和配置分离。**验收：**请求失败时日志能定位来源；仓库和日志中没有密钥。

### PY-07｜类型标注与数据校验 · P1 / L2

理解类型提示与 Pydantic 模型验证。**验收：**外部 JSON 字段缺失或类型错误时给出清楚错误，不把脏数据写入存储。

## 03 / 质量与交付

### PY-08｜测试与调试 · P1 / L2

使用 `pytest`、断言、fixture、断点和 mock。**验收：**清洗函数有正常、空值、异常三类测试，并能复现失败用例。

### PY-09｜并发与异步 · P1 / L2

区分线程、`async/await`、I/O 密集和 CPU 密集任务。**验收：**并发请求多个 API、有并发上限，并解释哪些场景不应使用异步。

### PY-10｜命令行工具 · P1 / L2

掌握 `argparse`、入口脚本和退出码。**验收：**将任务封装为可重复执行的 `python -m ... --date ...` 命令。

## 04 / 通关作品

### Data Pipeline

构建 `data_pipeline/` Python 包：输入日期范围，抓取公开 API → 校验 → 去重 → 导出 CSV/JSON。交付 README、结构化日志和至少 5 个自动化测试；在干净环境复现一次。
