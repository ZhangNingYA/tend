**本篇目标：**对明确允许访问的数据源，选择合适方式稳定提取信息。优先官方 API，再用合规 HTTP/HTML 解析，只有确需页面交互时才使用浏览器。

## 01 / 请求与页面结构

### WEB-01｜HTTP 基础 · P0 / L2

理解 URL、GET/POST、headers、cookie、状态码、JSON 和分页。**验收：**用开发者工具判断页面数据来自 HTML 还是接口，并能复现一次请求。

### WEB-02｜HTML、DOM 与选择器 · P0 / L2

理解标签、属性、CSS selector 和基本 XPath。**验收：**从两种不同结构的页面提取标题、时间和正文，并说明选择器边界。

### WEB-03｜Beautiful Soup · P0 / L2

掌握 `find`、`select`、文本清理和缺失节点处理。**验收：**静态页面可输出标准化数据；页面结构变化时能明确报错而不是静默写空值。

### WEB-04｜Scrapy 架构 · P0 / L2

理解 Spider、Request/Response、Item、Pipeline 和 Middleware。**验收：**搭建爬虫，覆盖分页、去重、错误记录和入库。

## 02 / 动态页面与运行可靠性

### WEB-05｜动态网页与公开接口 · P0 / L2

理解 JS 渲染、XHR/fetch 与等待条件。**验收：**解释为什么静态请求抓不到数据；先确认是否有可用公开接口，再决定是否自动化浏览器。

### WEB-06｜Playwright 或 Selenium · P1 / L2

理解浏览器上下文、定位器、等待和会话管理。**验收：**自动访问公开页面、翻页并提取数据；使用条件等待而非大量固定 `sleep`。

### WEB-07｜超时、重试与断点 · P1 / L2

掌握有限重试、退避、限流和断点续抓。**验收：**模拟网络中断后能够恢复，不产生无尽重试或大量重复记录。

### WEB-08｜增量同步与幂等 · P1 / L2

理解唯一标识、更新时间、水位线和幂等。**验收：**第二次运行只新增/更新记录；重复运行结果一致。

## 03 / 合规与监控

### WEB-09｜采集合规与安全边界 · P0 / L2

理解 `robots.txt`、服务条款、个人信息、鉴权和频率限制。**验收：**说明哪些数据不应抓取；不绕过验证码、付费墙或权限保护。

### WEB-10｜采集监控 · P1 / L2

关注成功率、采集量、异常记录和数据新鲜度。**验收：**能发现任务显示成功但实际抓取 0 条的情况，并留下告警/检查证据。

## 04 / 通关作品

### 合规增量采集任务

选择 1–2 个明确允许访问的公开 API 或数据源，建立每日增量任务。演示正常采集、断点恢复、去重、0 条数据告警和错误日志。
