**本篇目标：**让数据进入系统前有清晰结构、质量约束和来源记录；重复执行安全，查询性能可以解释。

## 01 / 关系模型与查询

### DATA-01｜关系数据库基本概念 · P0 / L2

理解表、行、列、主键、外键、约束和 NULL。**验收：**设计新闻、来源、抓取批次三张关联表，并解释主外键关系。

### DATA-02｜SQL 查询 · P0 / L2

掌握 `SELECT`、`WHERE`、`ORDER BY`、`LIMIT` 和聚合。**验收：**写出按来源、日期统计采集数量的查询。

### DATA-03｜JOIN 与分组 · P0 / L2

掌握 `INNER/LEFT JOIN`、`GROUP BY`、`HAVING` 和子查询。**验收：**查询过去 7 天各来源新增内容及失败次数。

## 02 / 写入与清洗

### DATA-04｜插入、更新与事务 · P0 / L2

理解 `INSERT`、`UPDATE`、`UPSERT`、事务和回滚。**验收：**同一批数据重复导入不重复；单批失败可以回滚。

### DATA-05｜PostgreSQL/MySQL 实操 · P0 / L2

掌握连接、schema、索引、迁移和连接池基本概念。**验收：**用 Python 完成数据库读写，并提供可重复执行的初始化脚本。

### DATA-06｜Pandas 清洗 · P0 / L2

掌握缺失值、去重、映射、`merge` 和 `groupby`。**验收：**处理重复、空值、日期不一致数据，输出清洗前后的统计。

### DATA-07｜数据标准化 · P1 / L2

统一时区、编码、日期、字段单位和枚举映射。**验收：**不同来源最终满足同一个 schema，并有转换规则说明。

## 03 / 数据可信度与性能

### DATA-08｜数据质量校验 · P1 / L2

理解完整性、唯一性、有效性、一致性和新鲜度。**验收：**自动拒绝关键字段为空或主键重复的数据。

### DATA-09｜索引与查询性能 · P1 / L1→L2

理解 B-tree 索引、`EXPLAIN` 基础和分页策略。**验收：**解释一条慢查询的原因，并通过索引或查询重写改善。

### DATA-10｜数据血缘与可追溯 · P1 / L2

记录原始来源、采集时间、版本和清洗规则。**验收：**任一数据记录可回溯到原始 URL/文件和处理批次。

## 04 / 通关作品

### 可重复导入的数据仓库切片

使用 SQL 建表和约束，导入至少 1,000 条合法公开或合成数据；编写至少 8 条查询。重复导入不产生重复数据，并能追溯来源。
